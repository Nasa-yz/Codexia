## 🇺🇸 English Description

### **Overview**

**Codexia** is an immersive digital experience that combines a high-fidelity landing page with a browser-based RPG adventure. Developed by **MiniCode Studio**, the project features a dark, luxurious aesthetic centered around themes of code, mystery, and ancient digital relics.

### **The Game**

Codexia is an adventure and mystery RPG where players explore the "Depths of the Digital Soul".

- **Engine:** Built using the GameMaker HTML5 runner.
- **Resolution:** Optimized for a 1366x768 canvas.
- **Scope:** The game features over 40 levels, 100+ collectibles, 15 bosses, and 10 unique biomes.

### **Landing Page Features**

The project's landing page serves as a portal to the world of Codexia, featuring:

- **Dynamic Visuals:** An interactive "Embers" particle system and fractal noise overlays.
- **Cinematic Animations:** Scroll-triggered reveal animations using the `IntersectionObserver` API.
- **Premium Typography:** Integration with Google Fonts (_Cinzel Decorative_, _Cinzel_, and _Lato_).

### **Tech Stack**

- **Game Engine:** GameMaker (HTML5).
- **Web Technologies:** HTML5, CSS3 (Variables, Flexbox, Grid), Vanilla JavaScript.
- **Design Elements:** SVG Filters, Backdrop Blurs, and Base64 encoded assets.

### **Project Structure**

```text
├── index.html            # Main Landing Page (Studio & Game Showcase)
├── codexia.html          # Game Runner (HTML5 Canvas)
└── codexiagame/          # Core game logic directory
    └── CODEXIA.js        # Main game script
```

## 🇧🇷 Descrição em Português

### **Visão Geral**

**Codexia** é uma experiência digital imersiva que combina uma landing page de alta fidelidade com uma aventura de RPG baseada em navegador. Desenvolvido pelo **MiniCode Studio**, o projeto apresenta uma estética sombria e luxuosa, centrada em temas de código, mistério e relíquias digitais antigas.

### **O Jogo**

Codexia é um RPG de aventura e mistério onde os jogadores exploram as "Profundezas da Alma Digital".

- **Motor (Engine):** Construído utilizando o runner HTML5 do GameMaker.
- **Resolução:** Otimizado para um canvas de 1366x768.
- **Escopo:** O jogo conta com mais de 40 níveis, 100+ colecionáveis, 15 chefes e 10 biomas únicos.

### **Recursos da Landing Page**

A landing page do projeto serve como um portal para o mundo de Codexia, apresentando:

- **Visuais Dinâmicos:** Um sistema de partículas de "Brasas" interativo e sobreposições de ruído fractal.
- **Animações Cinemáticas:** Animações de revelação acionadas por rolagem usando a API `IntersectionObserver`.
- **Tipografia Premium:** Integração com Google Fonts (_Cinzel Decorative_, _Cinzel_ e _Lato_).

### **Tecnologias Utilizadas**

- **Engine do Jogo:** GameMaker (HTML5).
- **Tecnologias Web:** HTML5, CSS3 (Variáveis, Flexbox, Grid), JavaScript Puro.
- **Elementos de Design:** Filtros SVG, Desfoque de fundo (Backdrop Blur) e ativos codificados em Base64.

### **Estrutura do Projeto**

```text

├── codexia.html          # Runner do Jogo (Canvas HTML5)

    └── CODEXIA.js        # Script principal do jogo
```
